# 🔗 Leads Tracker Chrome Extension

A simple and effective Chrome extension to save and track your favorite website links (leads) with just one click.


## 🚀 Features

- ✅ Save current tab with one click
- ✅ Store leads using `localStorage` (persist across browser sessions)
- ✅ View list of saved links
- ✅ Clean and minimal interface

---

## 🧠 Tech Stack

- HTML
- CSS
- JavaScript
- Chrome Extensions API
